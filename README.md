# LTPP在线开发平台
> 项目运行在Docker环境

## 注意事项
### 端口
- 1236（即时通讯系统注册，可忽略）
- 3000（音乐|开启SSL）
- 40000（邮箱系统）
- 40080（直播推流前端访问地址）
- 41935（直播推流）
- 28787（ChatGPT）
- 47272（即时通讯|开启SSL）
- 48787（后端|开启SSL）

### PHP插件
> 如果使用机器人接口需要卸载swoole插件

### Docker使用
> 若windows使用docker中自带的网络连接主机数据库，项目的配置文件的数据库ip使用host.docker.internal
